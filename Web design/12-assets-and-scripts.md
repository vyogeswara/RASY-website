## Notes

- All assets are optimized for web (WebP/PNG with responsive variants)
- MJS scripts are bundled by Framer and contain minified React + Framer Motion
- The `script_main.mjs` file bootstraps the entire application
- `ScrollColorText.mjs` handles the scroll-triggered text color animations
- For cloning, use Framer Motion library directly instead of these bundled MJS files

Hero Section Deep Dive Analysis
Overview
Reference: CosmoQ Tech Stack: React, Framer Motion (inferred), CSS-in-JS (Styled Components/Emotion pattern).

1. Typography
The site strictly uses the Inter family, split into two specific variants:

Headlines: Inter Display
Weights: 400, 500, 700, 900.
Style: Tight tracking (letter-spacing), often negative.
Body/UI: Inter
Weights: 400, 500, 600.
Style: Standard tracking, highly legible.
Key Findings from Source: Multiple @font-face declarations confirm the use of Inter Display for "Next-gen enterprise" text, ensuring that distinct high-fashion/modern tech look.

2. Color Palette & Tokens
Extracted CSS variables (Coins) from source:

Background: #000000 (Pure Black)
Accent Blue: #0175ff (Primary Brand Color)
Glass Border: rgba(255, 255, 255, 0.08) (Subtle white stroke)
Text Muted: #9ba9c4 (Blue-tinted grey for subheads)
Glow/Overlay: rgba(255, 255, 255, 0.12) (For hover states)
3. Layering & Architecture
The Hero section is constructed with a precise Z-axis stack:

Layer 1: Background (Bottom)
Element: Full-screen container (fixed or absolute).
Content: Video Loop (Horizon Glow/Planet).
Masking: Heavy use of CSS masking mask-image: radial-gradient(...) to fade the video edges into the black background, creating the "Horizon" effect rather than a hard video rectangle.
Source Code Evidence: .framer-17bqy5g uses mask: radial-gradient(50% 50% at 47.9% 93.9%, #0000 69%, #000 100%).
Layer 2: Texture/Overlays
Noise: A subtle static noise overlay (opacity: 0.03-0.05) adds "film grain" texture, preventing the gradient from banding and making it feel premium.
Particles: ParticleField (Stars) likely implemented via Canvas or SVG overlay.
Layer 3: Main Content
Container: Centered, Relative positioning.
Typography: Huge Headline (100px+ on desktop), Gradient Text ("with AI Agents").
Animations: Staggered Entry (Badge -> Text -> Button).
Layer 4: Navbar (Top)
Position: Fixed (top: 0).
Style: "Liquid Glass".
backdrop-filter: blur(10px) (Found in CSS).
background-color: Ultra-low opacity (e.g., rgba(255,255,255,0.01) or similar black tint).
Z-Index issue: The source code shows z-index: 8 for some fixed containers. In our implementation, we force z-index: 999 to ensure visibility over the complex 3D/Video layers.
4. Assets
Video: cloudniary (Previous extraction confirmed).
Fonts: Served from framerusercontent.com.
5. Animation Timing
Navbar: Static. It does NOT animate in. It appears instantly.
Hero Text:
Start Delay: 0.2s
Stagger: 0.1s - 0.2s between elements.
Easing: ease-out (Smooth deceleration).
key Recommendations for Replication
Enforce Inter Display: This isn't just "Inter". The Display variant is crucial for the headline look.
Mask the Video: Do not just place the video. Use mask-image: linear-gradient(to top, black, transparent) to recreate the "Horizon" fade.
Static Navbar: Ensure the navbar has NO entry transition, or it clashes with the hero load.
